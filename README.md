## IPLC为什么贵：你花钱买的是什么

IPLC（International Private Leased Circuit，国际私有租用专线）是运营商端到端的物理专用电路，从国内机房点对点直连海外，全程不经过公网。普通跨境线路再优质（不管是CN2 GIA还是9929），本质都是公网传输，晚高峰拥堵、限速都躲不开；IPLC独享带宽、延迟稳定，基本不受公网波动影响。

成本就贵在这里。一条物理专线的铺设和维护费用摆在那，带宽独享意味着不能像公网产品那样超售摊薄成本。在各类出海线路里，IPLC属于性能最好的一档，代价是价格整体高一个量级。

## 报价表上看不到的三个关键点

**超量之后是停机还是限速。** 上海电信入口的沪日、沪美流量版超量后是软限速，服务不中断；沪美IXP上云版明确标注超量停机，流量用完服务暂停，下个周期才恢复。跑直播、店铺运营这类断了就亏钱的业务，这一点比单价重要。

**IXP版要自备国内云厂前置。** 它的入口是云厂BGP优化通道，你需要自己搭配阿里云、腾讯云或UCloud等国内云资源做前置，这台云服务器的费用要算进真实月成本。手里已有云厂资源才划算，否则省下的钱会被抵掉。

**尽量月付起步。** 2022年底V2EX一个讨论帖里提到，当时国内IPEL商家收到过警告，帖内建议就是按月付。专线类服务的政策变动比普通云主机频繁，先月付跑一两个月，确认晚高峰表现再考虑长期用，沉没成本小得多。

## 常见问题

**IPLC和IEPL选哪个？** 两者都是点对点专线，区别在封装层级：IPLC是物理层电路，IEPL是以太网层专线，带宽调度更灵活、扩容方便，同线路下价格一般更低，实际体验差异很小。先看落地延迟和稳定性再选，MKCloud的广港IEPL端内延迟1~2ms，和深港IPLC一个量级。

**表里的价格是月付吗？年付有折扣吗？** 都是月付价。年付是否有优惠，以官网结算页显示为准，没有核验到的数字这里不写。

**端内延迟25ms，我用起来就是25ms吗？** 不一定。端内延迟只是入口机房到出口机房那一段，你感受到的总延迟等于本地到入口、端内、出口到目标服务器三段之和。沪美线124~134ms的端内延迟是物理距离决定的，选线路前先想清楚业务对延迟的容忍度。

**流量是双向计费吗？** IPLC的常见计费惯例是上下行双向计算，选购站给的1元/G参考价也基于这个口径。比较不同商家单价时，先确认计费方向，否则数字没有可比性。
